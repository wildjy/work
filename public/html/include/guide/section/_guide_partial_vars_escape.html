3-3. 이스케이프와 원문 — 괄호 두 겹과 세 겹

같은 값을 두 가지 괄호로 넣었다. 두 겹 {{ }} 는 태그를 글자로 보여 주고(이스케이프), 세 겹 {{{ }}} 는 태그를 살린다(원문).

결과

이스케이프와 원문 대조
무엇이 {{key}} — 이스케이프 {{{key}}} — 원문

✗ 속성값 자리에 세 겹 — 값의 따옴표에서 속성이 끊긴다

✓ 두 겹 — 따옴표가 &quot; 로 바뀌어 안전하다

  • 기본은 두 겹이다. 사용자가 입력한 값이 들어올 자리는 반드시 두 겹.
  • 세 겹은 마크업 조각 · 속성 묶음을 넘길 때만 쓴다 — 믿을 수 있는 값.
  • 세 겹은 마지막 수단이다. 먼저 물어본다 — 모양만 다르면 class(3-4) · 덩어리가 있다 / 없다면 넣고 빼기(4) · 속이 다르면 슬롯(5).
