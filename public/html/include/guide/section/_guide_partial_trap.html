  • 여러 화면이 쓰는 파셜의 변수에 기본값을 주었다 — 3-2
  • 끄려면 속성을 안 적었다 — "false" 를 넘기지 않았다 — 3-4
  • 속성값 자리(href · style)에 세 겹을 쓰지 않았다 — 3-3
  • 「어떤 화면에만」을 CSS 로 감추지 않았다 — 4
  • 슬롯 본문은 div 안이 아니라 template 에, include 와 같은 파일에 두었다 — 5
  • JSON 의 모든 항목이 모든 필드를 갖고, 0건 모양을 함께 만들었다 — 6
  • data-filter 는 조건 하나, 좁히면 use 를 안 본다 — 7
