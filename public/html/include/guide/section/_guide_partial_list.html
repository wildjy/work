6. 목록 — JSON + template

언제 — 같은 모양의 행이 반복되거나 행 수가 데이터에 따라 달라질 때. 행은 손으로 찍지 않는다 — 한 줄 모양(template)과 데이터(JSON)로 나눈다(React 의 map)

결과 — 전체 · !owner · 0건

전체 4건
owner 가 아닌 3건
걸리는 항목 없음
  • 채우는 자리 — {{key}} 글자로 · {{{key}}} 태그 살림 · {{@number}} 1부터 · {{@index}} 0부터.
  • 없는 키는 빈 칸이 된다 — 경고가 없다. 그래서 JSON 의 모든 항목이 모든 필드를 갖는다. 파셜 변수와 달리 기본값 문법도 없다(8).
  • 0건 모양 data-empty 는 목록을 만드는 커밋에서 함께 만든다 — 미루면 빈 화면이 검수에서 빠진다. 위 셋째 표가 그것이다.
  • 그 줄만 다른 모양은 JSON 항목에 "_tpl": "#tpl_다른것" — 위 첫째 표의 마지막 줄.
  • 컨테이너는 비워 둔다. JSON 은 한 건이어도 배열 [ { … } ] 로 적는다.

골라 그리기 — data-filter

JSON 은 그대로 두고 이 컨테이너에 그릴 항목만 고른다. 하나의 JSON 을 여러 컨테이너가 나눠 쓸 때 쓴다. 적을 수 있는 모양은 세 가지다.

data-filter 문법
적는 법 고르는 항목 위 demo_rows.json(4건)에서
owner owner 가 참인 것 1건 — 김진학
!owner owner 가 거짓인 것(필드가 없는 것 포함) 3건
role=편집자 role 이 편집자와 같은 것 2건 — 이하늘 · 박서준
안 적음 전부 4건

코드

결과 — owner 1건 · role=편집자 2건

owner 가 참인 것
role 이 편집자인 것
  • 조건은 하나만 적는다. 「이고 · 또는 · 같지 않음」은 없다 — 필요하면 JSON 에 그 뜻의 필드를 하나 두고("main": true) 그 이름으로 고른다.
  • = 가 있으면 늘 「같다」다. !type=plus 는 「plus 가 아님」이 아니라 이름이 !type 인 필드를 찾아 0건이 된다.
  • 값은 글자로 비교한다 — page=1 은 JSON 의 1 과 "1" 을 둘 다 고른다.
  • 거짓으로 치는 것 — 필드 없음 · false · 0 · 빈 글자 · null. 따옴표 친 "false" 는 참이다.
  • 0건이면 data-empty 모양이 나오고 브라우저 콘솔에 경고가 찍힌다. 산출물에는 고른 행만 남고 속성은 지워진다.
  • 값을 파셜 변수로 열어 두면 화면마다 고를 수 있다 — data-filter="{{show|use}}"(7).

template 을 여러 곳이 함께 쓰면 — 템플릿 전용 파셜

한 줄 모양을 두 곳 이상이 쓰면 template 요소만 담은 파셜을 따로 둔다. 위 데모 표 다섯 개가 모두 _guide_tpl_rows.html 하나를 쓰고, 드롭다운과 검색 드롭다운이 _ui_dropdown_tpl.html 하나를 함께 쓰는 것이 같은 모양이다.

실물 — 파셜 안에 목록을 둔다(_ui_dropdown.html)

목록 template 은 파셜로 빼도 되지만 슬롯 template 은 안 된다. 목록은 파셜 주입이 다 끝난 뒤 쓰이고, 슬롯은 전개 도중 쓰인다 — 사용처보다 뒤에서 include 한 슬롯 template 은 그때 아직 없다(5).

파셜 안 목록 템플릿의 {{name}} 은 파셜 변수와 같은 괄호다. 파셜에 같은 이름을 넘기면 파셜 변수가 먼저 먹는다 — 이름을 갈라 쓴다.

React 라면

파셜은 속성 네 개가 이 일을 한다 — data-source(데이터) · data-template(행 모양) · data-filter(거르기) · data-empty(0건). 조건을 자유롭게 쓰는 React 와 달리 거르기는 세 모양뿐이다.

더 알아보기 — 산출물 · 구현
