6. 지금 저장소에 적용된 것

개발 확인용 샘플 페이지가 이 구조의 실물이다

  • UI 하나에 구역 파셜 하나. 페이지는 틀(_sample_layout) + 구역 include 한 줄이다.
  • Sample.html 은 구역 15개를 모두 넣은 전체 모아보기, Sample_<UI>.html 은 하나씩. 목록은 LNB 「개발 확인용」이 data/common/lnb_dev.json 에서 그린다.
  • 점검 상세 알림의 본문(문단 세 개)은 4번 기준에 따라 _sample_modal.html 의 template 안에 직접 두었다 — 짧고 그 화면 전용이면 파일을 만들지 않는다.

실제 화면은 개발 확인용 샘플에서 열어 볼 수 있다.
