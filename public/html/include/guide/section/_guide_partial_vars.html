3. 값 넘기기 — 파셜은 한 벌, 값은 화면이 정한다

언제 — 문구 한 줄 · 숫자 · class 하나가 다르다고 파셜을 두 벌 만들고 싶어질 때. 다른 부분만 부르는 쪽이 넘긴다(React 의 props)

값 넘기기 문법
자리 적는 것
넘기는 쪽 (페이지) include div 에 data-이름="값"
받는 쪽 (파셜) 값이 들어갈 자리에 {{이름}} — 이름 모양은 바로 아래 3-0
두 겹 · 세 겹 {{key}} 글자로(이스케이프) · {{{key}}} 태그 살림(원문) — 3-3
기본값 {{key|기본값}} — 넘기지 않으면 기본값. 빈 기본값은 {{key|}} — 3-2

React 라면

파셜은 data-page-title="회원 관리" 로 넘기고 {{pageTitle|페이지 제목}} 으로 받는다. 같은 일을 React 는 이렇게 한다.

React 는 참 · 거짓과 객체를 넘기지만 파셜은 글자만 넘긴다 — class 전체 · 속성 이름 · 길이를 글자로 넘기는 이유다(3-4).
