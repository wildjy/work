4. 값 넘기기 — data-* 를 {{key}} 로 받는다

React 의 props 와 같은 자리다 — 문구 한 줄이 다르다고 파셜을 두 벌 만들지 않는다

4-1. 문법

변수 문법
문법 뜻
키 이름 data-page-title → {{pageTitle}} (케밥 → 카멜)
{{key}} HTML 이스케이프해서 넣는다
{{{key}}} 원문 그대로 넣는다 — 태그 · 속성 묶음을 넘길 때
{{key|기본값}} 넘기지 않으면 기본값. 빈 기본값은 {{name|}}

기본값이 없는 키를 넘기지 않으면 {{key}} 가 화면에 글자로 남는다. 여러 화면이 쓰는 파셜은 필수 값 외에는 전부 기본값을 준다.

data-* 키에 대문자를 쓰지 않는다. data-makeNew 는 브라우저에서 dataset.makenew 가 돼 브라우저만 치환에 실패한다(프리렌더는 성공). 속성은 큰따옴표로 적는다 — 작은따옴표는 그 반대로 프리렌더만 실패한다.

동작 — 같은 파셜에 값만 바꿔 넣는다

두 카드를 나란히 본다. 같은 파셜이고 다른 것은 data-* 뿐이다 — C 행은 두 화면 모두 {{notPassed}} 가 글자로 남고, F 행만 기본값으로 채워진다.

4-2. 문구가 아닌 자리 — class · 속성 · style

치환은 글자 바꿔치기라 넣는 자리를 가리지 않는다. 속성값이면 어디든 들어간다 — class 이름 · 속성 · style · href 안까지.

참 · 거짓을 문자열로 넘기지 않는다. data-attrs="false" 는 <input false> 가 되고 class 자리면 class="ui-btn false" 가 된다 — 끄는 방법은 「안 넘기는 것」 하나뿐이다.

{{{attrs|}}} 가 한 줄을 통째로 차지하면(공통 토글처럼 속성을 줄마다 적은 태그) 넘기지 않았을 때 프리렌더가 그 줄을 지운다 — 빈 줄이 남지 않게 하려는 것이다. 넘겼으면 남는다. 26.09.28 전의 prerender.js 는 넘겨도 지워 disabled 가 산출물에서만 빠졌다(원본 화면은 멀쩡해 눈에 안 띈다).

빈 값을 넘기는 것과 안 넘기는 것은 다르다. data-variant="" 는 「넘긴 것」이라 기본값을 이긴다. 기본값을 쓰려면 속성을 아예 적지 않는다.

속성 자리에 원문 치환을 쓸 때는 값에 " 가 없어야 한다. 하나라도 있으면 속성이 거기서 끊긴다 — 아래 4-3 의 href 행과 같은 이유다.

J 행의 data-flag-attrs="" 가 빈 값으로 기본값(hidden)을 밀어내 보이게 만든 것이다 — 위 경고의 「빈 값은 넘긴 것이다」를 그대로 쓴 자리다.

4-3. 이스케이프와 원문 — 어느 쪽을 쓰나

이스케이프와 원문 대조
무엇이 {{key}} — 이스케이프 {{{key}}} — 원문

4-4. 같은 괄호, 다른 규칙 — 파셜 변수와 목록 템플릿

파셜 변수와 목록 템플릿 대조
무엇이 파셜 변수 — data-* 목록 템플릿 — JSON

파셜 안 목록 템플릿에는 | 를 쓰지 않는다. 「안 넘긴 키를 그대로 둔다」는 보호는 기본값이 없을 때만 든다 — {{name|이름없음}} 은 파셜 변수 패스가 먼저 채워버려 listRender 가 볼 것이 남지 않는다.

개발단에 넘기는 표시 마커는 영문 한 단어만 쓰지 않는다. 키 형식이 [\w@.-]+ 라 {{Pro}} 는 키로 잡혀 지워지거나 치환된다 — 한글 · 공백 · 태그를 섞는다({{플랜 구독하기}}).

4-5. 조건문이 없다 — 기본값이 곧 else 가지다

{{a ? b : c}} 같은 문법은 없고, 앞으로도 두지 않는다. 파셜은 판단하지 않는다 — 어느 쪽인지는 부르는 화면이 이미 알고 있다. 그래서 조건이 아니라 결과를 넘긴다.

  • 두 갈래 — 기본값 쪽이 else 다.
  • 세 갈래 이상인데 모양만 다르다 — class 로 받는다(4-2).
  • 마크업째 있다 / 없다 — 경로 변수(5).
  • 본문이 다르다 — 슬롯(6). 구조가 다르다 — 항목의 _tpl(7).
  • 런타임에 갈린다 — 퍼블이 정할 일이 아니다. 마크업에 두고 개발단에 주석으로 넘긴다.

React 라면

파셜은 data-page-title="회원 관리" 로 넘기고 {{pageTitle|페이지 제목}} 로 받는다. 같은 일을 React 는 이렇게 한다.
