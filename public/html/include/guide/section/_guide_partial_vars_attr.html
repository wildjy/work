3-4. class · 속성 · style 자리

값은 문구 자리만이 아니라 속성 안 어디에나 들어간다. 치환은 글자 바꿔치기일 뿐이라, 무엇을 넘기든 그 글자가 그대로 박힌다.

① class — 모양만 다른 변형 · class 전체를 넘긴다

결과

② 속성이 있다 / 없다 — 속성 묶음을 통째로

결과 — ① 안 넘김 · ② 넘김

✗ false 를 넘겼다 — 결과가 input false 가 된다

✓ 끄려면 속성을 적지 않는다

③ style · 보였다 / 숨었다

결과 — ① 안 넘김 · ② 넘김

  • 모양만 다르면 class 전체를 넘긴다 — data-cls. 기본 class 까지 한 값이라 바꾸거나 뺄 수 있고, 세 갈래 이상이어도 파셜은 그대로다.
  • 있다 / 없다는 속성 글자를 통째로 넘긴다 — data-attrs="checked disabled". 끄는 방법은 「안 넘기는 것」 하나뿐이다.
  • 빈 값은 넘긴 것이다 — ③ 의 data-flag-attrs="" 가 빈 값으로 기본값(hidden)을 밀어내 보이게 만들었다.
  • 속성 자리에 세 겹을 쓸 때는 값에 " 가 없어야 한다 — 하나라도 있으면 속성이 거기서 끊긴다(3-3).

더 알아보기 — 실물 · 작은 차이
  • 실물 — 공통 체크박스 ui/_ui_checkbox.html 이 {{{attrs|}}} 로 속성 묶음을 받는다. ② 의 데모 파셜은 받은 값을 그대로 이어 넘길 뿐이다.
  • 값이 있는 속성은 &quot; 로 적는다 — data-attrs="maxlength=&quot;40&quot;". 날것 " 는 data 속성을 거기서 끊는다.
  • 공통 입력의 안내 문구 · 안내문 — data-placeholder 는 원문으로 받아 작은따옴표가 &#39; 로 바뀌지 않는다(큰따옴표는 넣지 않는다). 입력 아래 안내문은 글자가 아니라 data-slot-helper(마크업)로 넘긴다 — 오류 · 성공을 함께 두거나 링크를 넣을 수 있다.
  • class="a {{x|}}" 를 안 넘기면 끝에 공백 하나가 남는다. 화면엔 영향이 없고 산출물 비교에서만 보인다.
  • style 자리는 두 겹으로 둔다 — font-family: "Noto Sans" 처럼 따옴표가 든 값도 &quot; 로 나가 브라우저가 되돌려 읽는다.
