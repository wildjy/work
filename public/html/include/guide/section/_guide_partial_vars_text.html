결과

  • 속성 이름은 소문자와 하이픈만 쓴다(3-0).
  • 값은 큰따옴표로 감싸는 것이 기본이다 — 값 안에 큰따옴표가 있으면 바깥을 작은따옴표로 감싼다(26.10.06 부터 프리렌더도 작은따옴표 값을 읽는다).
  • prettier 는 값에 &quot; 가 든 속성을 작은따옴표로 바꾼다 — 그래서 처음부터 그 모양으로 적는다. 두 따옴표가 다 들어가야 할 때만 바깥을 큰따옴표로 두고 안쪽 큰따옴표를 &quot; 로 적는다.
  • 파셜 맨 위 주석에 어떤 data-* 를 받는지 적어 둔다 — 부르는 사람이 파셜을 열지 않아도 알 수 있게.

✗ 큰따옴표 안에 큰따옴표 — 속성이 거기서 끊긴다

✓ 값에 큰따옴표가 있으면 바깥은 작은따옴표

예제 — 값에 든 따옴표로 바깥 따옴표를 고른다

값 안에 큰따옴표만 → 바깥 작은따옴표 · 작은따옴표만 또는 따옴표 없음 → 바깥 큰따옴표 · 둘 다 → 바깥 큰따옴표 + 안쪽 큰따옴표만 &quot;. 함수 안 문자열은 작은따옴표로 써서 「둘 다」 한 가지로 모은다.
