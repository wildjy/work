결과

  • div 는 비워 둔다. 안에 무엇이든 들어 있으면 include 로 알아보지 못한다.
  • div 는 사라진다. 파셜 내용이 div 자리를 통째로 갈아 끼운다 — 이 div 에 class 를 줘도 남지 않는다. 감싸야 하면 바깥에 따로 감싼다.
  • 경로는 /html/include/<폴더>/_이름.html — 페이지 위치와 상관없이 늘 같다(2).
  • 파셜을 고쳤으면 pnpm run prerender — 안 돌리면 index 로 연 화면에 반영되지 않는다(14).
