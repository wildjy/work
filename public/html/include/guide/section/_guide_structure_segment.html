2. 세그먼트 둘 — section · body

슬라이스 안을 가르는 폴더는 이 둘뿐이다

section — 화면을 이루는 덩어리

한 페이지가 길어지면 구역 단위로 가른다. 페이지에는 include 줄만 남는다.

  • 목록 템플릿은 컨테이너와 같은 파일에 둔다 — 파셜이 목록보다 먼저 주입된다.
  • 화면에 보이지 않는 덩어리(토스트 · 모달의 실체)도 여는 버튼과 같은 파일에 둔다 — _sample_modal.html · _sample_toast.html.

닫음 표시를 목록 템플릿 바로 아래 두지 않는다. 프리렌더가 템플릿의 닫음 표시로 보고 지운다 — 구역 닫는 태그 바로 뒤로 올린다.

body — 슬롯 본문

모달 프레임에 넘길 본문. template 은 include 를 적은 파일에 남기고 내용만 여기 둔다.

template 요소째 파셜로 빼면 include 순서에 묶이고, 어기면 조용히 빈 본문으로 나간다. 배치별 동작표는 파셜(include) 사용법 5절.
