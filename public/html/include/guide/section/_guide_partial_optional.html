5. 덩어리를 통째로 넣고 뺀다 — data-source 를 변수로 연다

파셜 하나를 여러 화면이 쓰는데 한 덩어리만 어떤 화면엔 없어야 할 때. 문구가 아니라 마크업이 통째로 빠지므로 4 의 값 치환으로는 안 된다

① 경로를 넘긴 화면

② 넘기지 않은 화면

경로 변수 규칙
항목 규칙
빈 파셜 include/common/_none.html 은 0바이트 빈 파일이다. 주석 한 줄도 넣지 않는다 — 짧은 주석은 「구역 표시」로 판정돼 산출물에 그대로 남는다
기본값은 필수 기본값 없이 {{extra}} 로 두면 안 넘긴 화면에서 토큰째 fetch 한다 → 브라우저는 404, 프리렌더는 ! 파셜 없음
산출물에 뭐가 남나 replaceWith 라 컨테이너까지 사라진다 — 끈 화면의 산출물에는 죽은 마크업이 한 줄도 안 나간다
중첩도 그대로 치환이 끝난 뒤 다시 전개하므로(fillVars → expandPartials) 넣은 조각 안에 또 include 가 있어도 풀린다. 브라우저도 같은 순서다
실물 모달 프레임이 버튼 영역을 갈아 끼우는 data-footer 가 같은 모양이다 — 비우는 쪽이 아니라 바꾸는 쪽으로 쓴 예

CSS 로 감추지 않는다. display: none 으로 끄면 산출물에 죽은 마크업이 그대로 남아 개발자가 그것을 옮겨 쓴다. 「이 화면에는 없다」는 없애는 것이지 감추는 게 아니다.

조각이 두세 벌로 늘어나면 변수 대신 파셜을 나눈다. 이 방식은 있다 / 없다 한 가지일 때가 제일 깔끔하다 — 버튼이 없는 모달을 _ui_modal_alert.html 로 따로 둔 것이 그 판단이다.

React 라면

파셜은 경로를 넘기거나 넘기지 않는 것으로 가른다. 같은 일을 React 는 이렇게 한다.
