9. React 와 견주기

이름만 다르고 하는 일은 같다. React 를 써 봤다면 이 표가 가장 빠르다

React 대응
하려는 일 이 저장소 React

컴포넌트가 아니라 문자열 치환이다. 상태(useState)도 생명주기도 없고, props 로는 문자열만 넘어간다 — 객체·함수·JSX 는 못 넘긴다. 목록은 JSON 경로로, 마크업 덩어리는 슬롯으로 넘긴다.

값을 안 넘기면 빈칸이 되는 것이 아니라 {{key}} 가 화면에 그대로 남는다. 파셜에 기본값({{key|기본값}})을 적어 둔다.

key 가 없다. 대신 같은 파셜을 한 화면에 두 번 넣을 때는 id 가 겹치지 않도록 파셜이 data-id 를 받는다.
